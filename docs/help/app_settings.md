# Settings

The Settings page shows your profile information and system details.

## Profile

Displays your name, email address, and role as configured by your administrator. Profile information is updated automatically from your Google account on each login.

## System

Shows the current application environment (dev/prod) and the database name. Include this information when submitting a support request.

## Adding Preferences

To add app-specific user preferences, extend the `SettingsController` with a preferences action and add a preferences card to the settings template.
