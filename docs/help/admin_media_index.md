# Media

Search everything Phantasos stores.

- **Media or file ID** — paste a `media_id` or `media_file_id` from an application or a log; the
  first few characters are enough. A full ID that matches one item opens it directly.
- **Unused tickets** — upload tickets an application requested but never used. Hidden by default.

Media can contain student health information (DocGuard, ORMed). **Opening an item, and opening or
downloading any of its files, is recorded in the audit log** under your name.
